# الخادم (Supabase Edge Function)

دالة واحدة `assets/code/supabase/index.ts`، تُنشر بـ`verify_jwt = false`، ويكون التحقق بكلمات السر. كل طلب `POST` جسمه `{pass, action, ...}`. الجداول عليها RLS بلا سياسات، فلا وصول إليها إلا عبر الدالة (service role).

## كلمات السر الثلاث (جدول `settings`)

| النافذة | المفتاح | ماذا تفتح |
|---|---|---|
| المطور `admin` | `admin_pass_sha256` (بصمة) | كل شيء: كل الأقسام، والشبكة، والتصدير، والملفات |
| الرئيس `head` | `head_pass_sha256` (بصمة) | نموذج الطلب، وميزانية قسمه إن كان `is_head` في `teachers` |
| المعلم `teacher` | `teacher_pass` | الطلبات فقط، ولا ميزانية حتى لرئيس قسم دخل بها |

ضع البصمة بالأمر:
`update settings set value = encode(sha256(convert_to('الكلمة','UTF8')),'hex') where key = 'head_pass_sha256';`

## إجراءات الميزانية

| الإجراء | من | ماذا يفعل |
|---|---|---|
| `login` | الكل | يرجع `role` وقائمة `teachers` (name, department, is_head, nick, uid) |
| `budget_get` `{department, name}` | المطور، أو الرئيس لقسمه | ميزانية القسم. إن لم تُحفظ بعد يرجع معلمي القسم بلا شعب |
| `budget_save` `{department, name, data}` | المطور، أو الرئيس لقسمه | ينظّف `data` (`cleanBudget`) ثم يحفظ مع `updated_at` و`updated_by` |
| `budgets` | المطور | كل الميزانيات (الملخص، والشبكة، والتصدير) |
| `list` / `file` | المطور | الطلبات ومرفقاتها، ومنها ملفات الميزانية التي يرفعها الرؤساء (روابط موقّعة 10 دقائق) |

`cleanBudget` يحفظ فقط الشكل الموصوف في `data-format.md`:
- الحصص أعداد صحيحة من 0 إلى 40.
- يحذف الشعب غير المعروفة.
- يحذف `split` إن لم يساوِ مجموعه الخانة.

**مطابقة الخادم لملف البيانات:** `CLASSES` و`TRACKS` في أعلى الدالة يجب أن تطابق `school.grades`، و`MULTI` يجب أن يطابق مفاتيح `school.subjects`. عند تغيير الشعب، عدّلها وأعد نشر الدالة.

## ترتيب النشر

1. إن احتاجت الواجهة الجديدة إجراءً جديداً، تُنشر الدالة أولاً.
2. وإن رفض الخادم الجديد طلبات الواجهة القديمة، تُنشر الواجهة أولاً.
3. بعد نشر الدالة، اقرأها من الخادم وقارنها بالملف.
