# صيغة ملف البيانات «school-budgets» (الإصدار 1)

ملف JSON واحد بترميز UTF-8. افحصه دائماً بـ`scripts/check_data.py`.

```json
{
  "format": "school-budgets",
  "version": 1,
  "exported": "YYYY-MM-DD",
  "school":   { ... },
  "teachers": [ ... ],
  "budgets":  [ ... ]
}
```

## معرّفات الشعب

`10-1`…`10-7` العاشر · `11a-1` حادي عشر أدبي (يُعرض «11د1») · `11s-1` حادي عشر علمي («11ع1») · `12a-1` · `12s-1`.
تُعرض في ورقة التوزيع: `10/1`، `11د1`، `11ع1`، `12د1`، `12ع1`.

## school (يصير `web/school-data.js`)

| الحقل | المعنى |
|---|---|
| `grades` | الصفوف بترتيب العرض: `{track, label, short, classes[]}`. `track` مفتاح `periods` في الميزانية (`g10`, `g11a`, `g11s`, `g12a`, `g12s`). |
| `hidden` | شعب موجودة في نموذج الوزارة ولا تفتحها المدرسة هذا العام. تُخفى ما لم يكن لمعلم حصص فيها. |
| `official` | المقرر الرسمي: `{مادة: {شعبة: حصص}}`، والمادة بالاسم الذي تكتبه ورقة «المواد». الخانة المخالفة له حمراء، والمادة بلا مقرر في شعبة رمادية. |
| `subjects` | الأقسام متعددة المواد فقط: `{قسم: [مواد]}`. قسم غير مذكور هنا مادته اسمه. |
| `sheetSubject` | اسم المادة في المنصة → اسم عمودها في ورقة التوزيع، حين يختلفان (مثل «تاريخ الكويت» → «الاجتماعيات»). |
| `gridCols` | أعمدة «ميزانية كل الأقسام» بترتيب الورقة: `[العمود, القسم = العمود, المادة داخل القسم = لا شيء]`. القسم `null` يعني عموداً للقراءة فقط. |
| `form` | ديباجة النموذج المنزَّل: `year`، `ministry`، `region`، `school`، `principal`، `logos: {ministry, school}` (مسارات صور داخل `web/`). |

## teachers (جدول `teachers`)

`{name, nick, uid, department, is_head}`
- `name` الاسم الكامل، وهو المفتاح في كل مكان (فريد).
- `nick` اسم الشهرة كما في ورقة «المعلمون»، ويظهر في النموذج والشبكة.
- `uid` معرّف المعلم في نظام الجدول (اختياري).
- `is_head` رئيس القسم. هو وحده من يفتح ميزانية قسمه بكلمة الرؤساء.

## budgets (جدول `budgets`)

`{department, updated_at, updated_by, data}`، و`data`:

```json
{
  "periods":  {"g10": 6, "g11a": 6, "g11s": 6, "g12a": 6, "g12s": 6},
  "required": 9,
  "note": "ملاحظة القسم",
  "teachers": [
    {
      "name": "الاسم الكامل",
      "cells": {"10-1": 6, "11s-2": 3},
      "note": "ملاحظة المعلم",
      "subjects": ["الجيولوجيا", "التربية البيئية"],
      "subj": {"11s-2": "الجيولوجيا"},
      "split": {"11s-2": {"الجيولوجيا": 2, "التربية البيئية": 1}}
    }
  ]
}
```

- `periods` حصص الأسبوع للصف، تُستعمل حين لا يكون للمادة مقرر في الشعبة. `null` يعني غير محدد.
- `cells` الشعب وحصص المعلم فيها. غياب الشعبة يعني أنه لا يدرّسها.
- `subjects` و`subj` للأقسام متعددة المواد: مواد المعلم، ومادة كل شعبة.
- `split` لمعلم يدرّس مادتين في الشعبة نفسها. يُعتمد فقط ما دام مجموعه يساوي `cells[شعبة]`، وإلا تجاهله الخادم والواجهة.
- `required` العدد المطلوب من المعلمين (اختياري).
