# ملاحظات الجدول المدرسي

منصة شخصية يرسل بها المعلمون ملاحظاتهم على الجدول، ويحوّلها المطور قيوداً بلغة ورقة «القيود» في ملف الجدول.

- الرابط: https://teacher-requests.onrender.com

## خريطة المستودع
| المجلد / الملف | ما فيه |
|---|---|
| `CLAUDE.md` | تعليمات العمل والقرارات الثابتة (المرجع الأول) |
| `HOSTED.md` | النسخة المنشورة وطريقة عملها |
| `web/` | الواجهة (موقع ثابت على Render) |
| `supabase/` | الدالة `functions/api`، والترحيلات، والبذور |
| `tools/` | الحراس (`guards.py`) والاختبارات ومستورد الشيت وباني صفحة الميزانيات المستقلة |
| `skills/school-budgets/` | مهارة الميزانيات ونسخة كودها |
| `docs/` | المواصفات المعتمدة بتواريخها |

## قبل كل دفع
```bash
python3 tools/guards.py
```
