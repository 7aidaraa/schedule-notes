# منصة طلبات المعلمين

رابط واحد للجميع:
- كلمة سر المعلم: يظهر نموذج فيه الاسم الرباعي والطلب والسبب ومرفق اختياري (PDF أو صورة).
- كلمة سر المدير: تظهر كل الطلبات، ومع كل طلب زر "تم ✓"، وخانة ملاحظات، وزرّان لعرض المرفق وتحميله.

البيانات تُحفظ في جدول Google Sheets تملكه أنت، والمرفقات تُحفظ في مجلد على Drive اسمه "مرفقات طلبات المعلمين".

## النشر (مرة واحدة، نحو 3 دقائق)
1. افتح `sheets.new` لإنشاء جدول جديد، وسمّه "طلبات المعلمين".
2. من قائمة Extensions اختر Apps Script.
3. احذف محتوى `Code.gs` والصق مكانه محتوى ملف `Code.gs` من هنا.
4. اضغط زر **+** ثم HTML، وسمِّ الملف `Index` تماماً، والصق فيه محتوى `Index.html`.
5. من أيقونة الترس (Project Settings) انزل إلى Script Properties وأضف:
   - `ADMIN_PASS` وقيمته كلمة سرك أنت.
   - `TEACHER_PASS` اختياري، وقيمته الافتراضية `معلم`.
6. اضغط Deploy ثم New deployment ثم Web app، واضبط:
   - Execute as: **Me**
   - Who has access: **Anyone**
7. اضغط Deploy ووافق على الصلاحيات. إن ظهرت عبارة "Google hasn't verified this app" فاضغط Advanced ثم Go to.
8. انسخ الرابط الذي ينتهي بـ `/exec` وأرسله للمعلمين.

## عند تعديل الكود لاحقاً
اختر Deploy ثم Manage deployments ثم ✏️، واختر Version: New version ثم Deploy. يبقى الرابط كما هو.
